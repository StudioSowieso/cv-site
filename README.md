# sabiendouven.nl

Cv-onepager van Sabien Douven, gebouwd met Next.js (App Router), TypeScript en gewone CSS.

## Lokaal draaien

```bash
npm install
npm run dev
```

## Inhoud aanpassen

Alle teksten (projecten, werkervaring, skills, opleiding, talen en contactgegevens) staan in
[`lib/data.ts`](lib/data.ts). Afbeeldingen staan in `public/img`.

## Deployen

Elke push naar `main` wordt automatisch gedeployed door Vercel.
